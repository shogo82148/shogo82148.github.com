Response Streaming

2023年4月に発表されたAWS Lambdaの新機能です。

  • AWS Lambda レスポンスストリーミングの紹介
  • Introducing AWS Lambda response streaming

従来のLambda関数は処理がすべて完了したあとでないと結果を返すことができませんでした。 Response Streamingを利用すると、処理の途中であっても段階的に処理結果を返すことができます。
