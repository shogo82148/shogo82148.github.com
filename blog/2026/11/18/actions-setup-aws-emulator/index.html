AWS EmulatorのセットアップをするGitHub Actionを書いた

背景・目的

11月11日にAWS Emulatorが公開されました。 AWSの環境を手元で再現できるツールです。

  • AWS Emulator を使用してローカルで AWS に対してアプリケーションをテストする

手元でテストができるようになったら、GitHub Actionsでテストしたくなりますよね。 しかし、実際にGitHub ActionsにAWS Emulatorを導入するのは意外と面倒です。

  • .debファイルのダウンロード
  • 署名の検証
  • AWS Emulatorの起動
  • AWS Emulatorがリクエストを受け付けられるようになるまで待機
  • 接続用の環境変数の設定

やることが多い。

毎回この分量書くのつらいから、公式からGitHub Action提供されないかな

https://t.co/W5drYuDYU9

— f96fd3a0-bdb9-4f10-b69f-8f765c1d341c ICHINOSEShogo (@shogo82148) November 15, 2026

公式から提供される気配をまったく感じないので作っちゃいました。

  • shogo82148/actions-setup-aws-emulator

使い方

GitHub Action を呼び出すだけです。

on:
  push:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: shogo82148/actions-setup-aws-emulator@v0
      - run: aws sts get-caller-identity

テレメトリーはデフォルトで有効になっています。気になる人は明示的にオフにしてください。

on:
  push:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: shogo82148/actions-setup-aws-emulator@v0
        with:
          telemetry: "off"
      - run: aws sts get-caller-identity

実際に使用する際は、CIが予期せず壊れないよう、バージョンを固定するのが望ましいでしょう。

on:
  push:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: shogo82148/actions-setup-aws-emulator@v0
        with:
          aws-emulator-version: "1.0.508" # 2026-11-18 21:56 現在最新のバージョンを使用
          telemetry: "off"
      - run: aws sts get-caller-identity

余談

GitHub Actionsのマーケットプレイスに「Setup AWS Emulator」の名前で出そうと思ったら、もうすでに取られていた・・・。

  • Setup AWS Emulator

みんな考えることは一緒。 なんか代わりのいい名前募集してます。

まとめ

AWS EmulatorをGitHub Actionsで使用するために、 セットアップをしてくれるGitHub Actionを書きました。

  • shogo82148/actions-setup-aws-emulator

ぜひご利用ください。
